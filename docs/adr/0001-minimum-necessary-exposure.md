# Minimum-necessary exposure of personal data

ERNS handles student personal data under RA 10173, and officers previously passed participant details through informal channels. We decided officers see aggregate read and acknowledgement counts only (never email addresses or per-recipient failure detail), Attendance Staff see name plus confirmation reference for their assigned event only, and QR tokens are opaque: the least-privilege visibility that still lets each role do its job, so a future request for broader access must justify itself against this rule.
